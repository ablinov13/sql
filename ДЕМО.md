Команды в **Git Bash**, из папки `sql`:
```bash
cat data/books.txt                     # весь файл
grep "Детектив" data/books.txt         # все детективы

grep -c "" data/books.txt              # число строк → 25
grep "Толкин" data/books.txt | wc -l   # книг Толкина → 4
```

## Лаба 1: DB Browser for SQLite
Показывай «вживую», так нагляднее всего.

1. **Новая база данных** (Ctrl+N) → сохранить как `lab1.db` в папке `sql`. Окно «Изменить определение таблицы» закрыть кнопкой **Отмена**.
2. Вкладка **Execute SQL** (Выполнить SQL).
3. Ввести и выполнить (**F5** или Ctrl+Return) по очереди:

**Создание таблицы:**
```sql
CREATE TABLE books (
    title  TEXT    NOT NULL,
    genre  TEXT    NOT NULL,
    price  INTEGER NOT NULL,
    year   INTEGER NOT NULL,
    author TEXT    NOT NULL
);
```

**Загрузка данных.** Вводить 25 строк руками долго, поэтому нажми кнопку «Открыть SQL-файл» (папка на панели вкладки) → `lab1\lab1.sql` → **F5**. Скрипт сам пересоздаёт таблицу (`DROP TABLE IF EXISTS`) и вставляет 25 книг одним `INSERT`. Можно показать одну вставку руками:
```sql
INSERT INTO books VALUES ('Тестовая книга', 'Роман', 100, 2024, 'Иван Иванов');
DELETE FROM books WHERE title = 'Тестовая книга';
```

**Проверка, что данные загружены:**
```sql
SELECT COUNT(*) FROM books;          -- 25
SELECT * FROM books;
```
(или вкладка **Browse Data** → таблица `books`)

**Запрос 1:** детективы дешевле 450 руб. (3 строки)
```sql
SELECT title, price FROM books WHERE genre = 'Детектив' AND price < 450;
```

**Запрос 2:** 5 самых дорогих книг
```sql
SELECT title, genre, price FROM books ORDER BY price DESC LIMIT 5;
```

**Запрос 3:** количество книг и средняя цена по жанрам (7 строк)
```sql
SELECT genre, COUNT(*) AS books_count, CAST(ROUND(AVG(price)) AS INTEGER) AS avg_price
FROM books
GROUP BY genre
ORDER BY books_count DESC, genre;
```

**Если попросят что-то ещё:**
```sql
SELECT * FROM books WHERE year = 2022;                       -- книги 2022 года
SELECT * FROM books WHERE price BETWEEN 500 AND 700;         -- диапазон цен
SELECT author, COUNT(*) FROM books GROUP BY author;          -- книг у каждого автора
SELECT * FROM books WHERE title LIKE '%Кольца%';             -- поиск по части названия
SELECT MIN(price), MAX(price), AVG(price) FROM books;        -- мин/макс/среднее
```
4. **Записать изменения** (Ctrl+S).

Если выделить один запрос мышью и нажать F5, выполнится только он.

## Лабы 2–5: Visual Studio
Конфигурация **Debug | x64**. Для каждой лабы: правый клик по проекту → **Назначить запускаемым проектом** → **Ctrl+F5**.

### Лаба 2 (`lab2`)
- Ожидаемый вывод: «Загружено строк: 25» и три таблицы.
- Показать в `main.cpp`: `sqlite3_open` (подключение), `CREATE TABLE`, `sqlite3_prepare_v2` + `sqlite3_bind_*` + `sqlite3_step` (вставка), цикл `while (sqlite3_step(stmt) == SQLITE_ROW)` (чтение результата).

### Лаба 3.1 (`lab3`)
- Вывод: 11 авторов, 25 книг, 3 запроса через DAO.
- Показать:
  - `BookDao.h`: методы `insert`, `getAll`, `getByGenre`, `getByPriceRange`, `getAllWithAuthors`;
  - `main.cpp`: `Book book; ... bookDao.insert(book);` (добавление через объект) и `for (const Book& b : bookDao.getByGenre(...))` (перебор списка);

### Лаба 4 (`lab4`)
- Вывод: группировка по жанрам, диапазон цен 500–700, книги британских авторов (JOIN).
- Показать `Storage.h`: `make_table`/`make_column` (структура ↔ таблица) и в `main.cpp` `storage.insert(...)`, `storage.get_all<Book>(where(between(...)))`, `group_by`, `inner_join`.
- Если спросят «почему не ORMLite»: ORMLite только для Java, для C++ взята аналогичная библиотека sqlite_orm.

## Частые вопросы
| Вопрос | Ответ |
|---|---|
| Почему SQLite, а не H2? | H2 — встраиваемая БД для Java. Для C++ встраиваемая БД — SQLite: тоже без сервера, база в одном файле |
| Что такое DAO? | Класс, который прячет весь SQL одной таблицы. Программа работает с объектами и вызывает `insert`/`getXxx` |
| Что такое ORM? | Библиотека сама сопоставляет структуры с таблицами и строит SQL. Мы описываем схему один раз в `Storage.h` |
| Зачем `?` в запросах? | Подготовленный запрос: значения подставляются отдельно, нет SQL-инъекций и проблем с кавычками |
| Зачем `SetConsoleOutputCP(CP_UTF8)`? | Чтобы консоль Windows показывала русский текст из UTF-8 |
| Зачем `charset=utf-8` в лабе 5? | Чтобы браузер правильно показал русские буквы |

Подробные объяснения по каждой лабе — в `labN/ПОЯСНЕНИЕ.md`.
