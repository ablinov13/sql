# Лаба 2: подключение к встраиваемой БД из программы

## Что требовалось
Скачать драйвер JDBC для встраиваемой БД H2, подключить его к проекту Java, подключиться к базе из программы, создать таблицу, загрузить данные и выполнить 2–3 SELECT. Язык разрешили любой, поэтому делаем на **C++**.

## Чем заменили Java/H2/JDBC
| В задании (Java) | У нас (C++) |
|---|---|
| встраиваемая БД **H2** | встраиваемая БД **SQLite**: тоже без сервера, база — один файл `lab2.db` |
| драйвер JDBC (`h2.jar`) | библиотека SQLite: файлы `sqlite3.c` + `sqlite3.h` в `third_party/sqlite`, собираются в `sqlite.lib` (проект `sqlite` в решении) |
| подключить jar к проекту | ссылка на проект `sqlite` (References) + путь к `sqlite3.h` в `common.props` |
| `DriverManager.getConnection("jdbc:h2:...")` | `sqlite3_open("lab2.db", &db)` |
| `Connection` | `sqlite3*` |
| `Statement.execute(sql)` | `sqlite3_exec(db, sql, ...)` |
| `PreparedStatement` + `setString/setInt` | `sqlite3_prepare_v2` + `sqlite3_bind_text/bind_int` |
| `executeUpdate()` | `sqlite3_step()` → `SQLITE_DONE` |
| `ResultSet.next()` / `getString(i)` | `sqlite3_step()` → `SQLITE_ROW` / `sqlite3_column_text(stmt, i)` |
| `close()` | `sqlite3_finalize(stmt)`, `sqlite3_close(db)` |

## Как работает программа ([main.cpp](main.cpp))
1. **`SetConsoleOutputCP(CP_UTF8)`**: консоль Windows начинает понимать UTF-8, иначе русский текст выйдет кракозябрами. Вместе с флагом компилятора `/utf-8` (в `common.props`) это решает проблему кодировки.
2. **Подключение:** `sqlite3_open` открывает файл `lab2.db` или создаёт его.
3. **Создание таблицы:** `DROP TABLE IF EXISTS` + `CREATE TABLE` через `execSql` (обёртка над `sqlite3_exec`). DROP нужен, чтобы при повторном запуске не было дублей.
4. **Загрузка данных:** файл читается построчно (`std::getline`), строка режется по запятым. Для вставки один раз готовится запрос `INSERT INTO books VALUES (?, ?, ?, ?, ?)`, потом для каждой строки:
   - `sqlite3_bind_*`: подставить значения вместо `?`;
   - `sqlite3_step`: выполнить;
   - `sqlite3_reset`: сбросить, чтобы использовать запрос снова.

   **Зачем `?`, а не склеивать строку SQL:** не надо экранировать кавычки, и нет SQL-инъекций.

   **Зачем `BEGIN`/`COMMIT`:** все 25 вставок идут одной транзакцией. Без неё SQLite сохраняет файл после каждой вставки, а это медленно.
5. **Запросы:** функция `printQuery` готовит запрос, печатает имена колонок (`sqlite3_column_name`) и в цикле `while (sqlite3_step(stmt) == SQLITE_ROW)` печатает значения (`sqlite3_column_text`).
6. **Закрытие:** `sqlite3_finalize` для каждого запроса, `sqlite3_close` в конце.

Функция `pad` выравнивает колонки. Она считает символы, а не байты: русская буква в UTF-8 занимает 2 байта, и обычный `std::setw` сбил бы таблицу.
