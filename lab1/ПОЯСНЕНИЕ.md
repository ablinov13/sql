# Лаба 1: SQLite-клиент и язык SQL

## Что требовалось
1. Скачать любой клиент SQLite.
2. Создать таблицу и загрузить данные из предыдущего задания, **используя язык SQL**.
3. Выполнить 2–3 запроса SELECT.

## Что сделано
- Клиент: **DB Browser for SQLite** (у тебя уже установлен в `C:\Program Files\DB Browser for SQLite`).
- Весь SQL лежит в одном файле [`lab1.sql`](lab1.sql): создание таблицы, 25 `INSERT`, три `SELECT`.

## Как выполнить самому
1. Открыть DB Browser for SQLite → **Новая база данных** → сохранить как `lab1.db`. Окно «Изменить определение таблицы» закрыть (**Отмена**): таблицу создаст скрипт.
2. Вкладка **Выполнить SQL** → кнопка «Открыть SQL-файл» → `lab1/lab1.sql`.
3. **F5** (выполнить всё). Внизу показывается результат последнего запроса.
4. Чтобы увидеть результат конкретного запроса: выделить его мышью и нажать **Shift+F5** («выполнить текущую строку») или Ctrl+Return.
5. **Записать изменения** (Ctrl+S).

## Разбор SQL
| Оператор | Что делает |
|---|---|
| `DROP TABLE IF EXISTS books` | удаляет таблицу, если она уже есть, чтобы скрипт можно было запускать повторно без ошибки «table already exists» |
| `CREATE TABLE books (...)` | создаёт таблицу. `TEXT` — строка, `INTEGER` — целое число, `NOT NULL` — значение обязательно |
| `INSERT INTO books (...) VALUES (...), (...)` | добавляет строки. Один `INSERT` с 25 наборами значений. Строки в одинарных кавычках, числа без кавычек |
| `SELECT ... FROM ... WHERE` | выборка строк по условию |
| `ORDER BY price DESC` | сортировка по цене, `DESC` — по убыванию |
| `LIMIT 5` | взять только первые 5 строк |
| `GROUP BY genre` | разбить строки на группы с одинаковым жанром |
| `COUNT(*)`, `AVG(price)` | агрегатные функции: количество строк в группе и среднее значение |
| `ROUND`, `CAST(... AS INTEGER)` | округлить среднее и убрать `.0` |
| `AS books_count` | псевдоним (имя) столбца в результате |

## Запросы и результаты
1. **Детективы дешевле 450 ₽:** `WHERE genre = 'Детектив' AND price < 450` → 3 книги (Экройд 430, Собака Баскервилей 390, Этюд в багровых тонах 360).
2. **Топ-5 самых дорогих:** `ORDER BY price DESC LIMIT 5` → Братство Кольца 2300, Война и мир 1450, Возвращение короля 1080, Две крепости 1050, Анна Каренина 980.
3. **Статистика по жанрам:** `GROUP BY genre` → у каждого жанра количество книг и средняя цена (самый дорогой жанр — Фэнтези, 1288 ₽).

Третий запрос сложнее, чем в образце (там были только `WHERE` и `ORDER BY`). Он показывает, зачем в задании нужна колонка-категория: по ней группируют.

## Чем SQL лучше grep из лабы 0
`grep` ищет подстроку в тексте. SQL знает колонки и типы, поэтому умеет сравнивать числа (`price < 450`), сортировать, группировать и считать.
