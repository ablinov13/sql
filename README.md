# Лабораторные по базам данных (C++, Visual Studio 2022)

Предметная область: **книжный магазин** (`data/books.txt`, `data/authors.txt`).

## Как открыть и запустить
1. Открыть `DbLabs.sln` в Visual Studio 2022 (нужна нагрузка «Разработка классических приложений на C++»).
2. Конфигурация **Debug | x64**.
3. В обозревателе решений: правый клик по нужной лабе → **Назначить запускаемым проектом**.
4. **Ctrl+F5** (запуск без отладки: окно консоли не закроется сразу).

Рабочая папка у всех проектов — корень решения (задано в `common.props`), поэтому программы сами находят `data\books.txt` и кладут туда файлы `.db`.

## Отчёты и скриншоты
- `reports/Лаба1.docx … Лаба5.docx` — отчёты в оформлении образца. ФИО, группу и руководителя впиши на титульнике сам. Если что-то правишь, обнови оглавление: правый клик → «Обновить поле».
- `screenshots/` — настоящие снимки окон (консоль, DB Browser, браузер).
- `tools/` — скрипты, которыми всё это сделано: `make_reports.py` (отчёты из образца `Лаба2 (2).docx`), `update_toc.ps1` (оглавление через Word), `shot*.ps1` (скриншоты), `build.ps1` (сборка из командной строки). Для сдачи они не нужны.

## Сторонний код
- `third_party/sqlite`: SQLite 3.50.4 (amalgamation, public domain).
- `third_party/sqlite_orm`: sqlite_orm 1.9.1 (header-only, лицензия AGPL-3.0 — для учебной работы подходит; github.com/fnc12/sqlite_orm).
