# Лаба 0: предметная область и данные

## Что требовалось
Выбрать свою предметную область и придумать таблицу: минимум 3 колонки (текст, текст-категория, число). Внести 20–30 записей в текстовый файл через запятую.

## Что сделано
Предметная область: **книжный магазин**.

Файл [`data/books.txt`](../data/books.txt): 25 строк, по одной книге на строку:

```
название,жанр,цена,год,автор
Мастер и Маргарита,Роман,650,2021,Михаил Булгаков
```

| Колонка | Тип | Зачем |
|---|---|---|
| название | текст | основная колонка (по заданию 1-я, текст) |
| жанр | текст-категория | 7 жанров повторяются, поэтому по ним можно группировать (`GROUP BY`) |
| цена | число, ₽ | от 340 до 2300, можно выбирать диапазоны (`BETWEEN`, `<`, `>`) |
| год | число | год издания, можно фильтровать |
| автор | текст | понадобится в лабах 3–4, где нужна вторая таблица |

Колонок больше трёх: по заданию «больше можно, меньше нельзя».

Второй файл [`data/authors.txt`](../data/authors.txt) (`имя,страна`, 11 авторов) нужен для лаб 3 и 4, где таблиц две: `authors` и `books`.

**Правило файла:** внутри значений нет запятых (поэтому, например, «Я, робот» не взят), иначе строка разобьётся неправильно.

## Поиск по файлу с grep
«Предыдущее задание (с grep)» — это поиск по текстовому файлу без всякой БД. Примеры (Git Bash, он ставится вместе с Git):

```bash
grep "Детектив" data/books.txt          # все детективы
grep ",2022," data/books.txt            # книги 2022 года
grep -c "" data/books.txt               # сколько строк (25)
grep "Толкин" data/books.txt | wc -l    # сколько книг Толкина (4)
```

`grep` ищет строки, в которых есть подстрока, но не понимает колонок: `grep 2022` найдёт и цену 2022, если такая будет. Поэтому дальше переходим на SQL, где можно написать `WHERE year = 2022`.
