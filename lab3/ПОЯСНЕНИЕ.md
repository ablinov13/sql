- Выборка: через `XxxDao.getXxx`, затем перебор списка объектов.

- Замечания со слайда:
  1. `System.out.println` (у нас `std::cout`) внутри методов DAO не использовать вообще;
  2. исключения внутри DAO не ловить, а передавать наверх и обрабатывать в `main`;
  3. результат работы и отладочные сообщения выводить только в `main`.

## Что такое DAO и зачем он нужен
**DAO (Data Access Object)** — класс, который прячет внутри себя весь SQL для одной таблицы. Остальная программа работает с обычными объектами (`Book`, `Author`) и вызывает методы `insert`, `getAll`, `getByGenre`. Про SQL она ничего не знает.

Зачем это нужно:
- SQL собран в одном месте, а не размазан по `main`;
- `main` читается как описание логики: «добавить автора», «получить книги жанра»;
- если поменять БД или структуру таблицы, правится только DAO.

Сравни с лабой 2: там `main` сам делал `prepare`/`bind`/`step`. Теперь это внутри `BookDao::insert`.

## Классы и методы
**`Database`** — подключение к БД.
- Конструктор вызывает `sqlite3_open`, деструктор — `sqlite3_close`. Это **RAII**: ресурс захватывается в конструкторе и освобождается в деструкторе автоматически, даже если вылетело исключение.
- `exec(sql)` — SQL без результата.
- `lastInsertId()` — id только что вставленной строки.
- Копирование запрещено (`= delete`), иначе две копии закрыли бы одно соединение дважды.

**`Statement`** — подготовленный запрос, тоже RAII (`sqlite3_finalize` в деструкторе).
- `bind(i, значение)` — подставить значение вместо i-го `?`.
- `step()` — выполнить шаг: `true` — есть строка, `false` — конец.
- `columnText(i)`, `columnInt(i)` — прочитать колонку текущей строки.

**`DbException`** — своё исключение (наследник `std::runtime_error`). Каждая ошибка SQLite превращается в `throw DbException(...)`.

**`AuthorDao`**: `dropTable`, `createTable`, `insert(Author)` → id, `getAll()`, `getByName(name)` → `std::optional<Author>` (`optional` значит «автор может не найтись», вместо `nullptr`).

**`BookDao`**:
- `dropTable`, `createTable` (`author_id ... REFERENCES authors(id)` — внешний ключ);
- `insert(Book)`;
- `getAll()`;
- `getByGenre(genre)` — `WHERE genre = ?`;
- `getByPriceRange(from, to)` — `WHERE price BETWEEN ? AND ?`;
- `getAllWithAuthors()` — `JOIN` двух таблиц.

## Как выполнены замечания
- В `*Dao.cpp` и `Database.cpp` нет ни `cout`, ни `try/catch` (проверено поиском).
- Ошибка внутри DAO делает `throw`. Исключение проходит через все вызовы и ловится в `main` двумя `catch`: сначала `DbException` (ошибка БД), потом `std::exception` (прочие, например нет файла).
- Весь вывод в `main`.

## Порядок в main
1. `Database db("lab3.db")` — подключение.
2. Удаление таблиц: сначала `books`, потому что она ссылается на `authors`. Потом создание: сначала `authors`.
3. Для каждой строки `authors.txt`: `Author author; ... authorDao.insert(author);`
4. Для каждой строки `books.txt`: найти автора `authorDao.getByName`, взять его `id`, создать `Book` и `bookDao.insert(book)`.
5. Выборки `getAll`, `getByGenre("Фантастика")`, `getByPriceRange(500, 700)`, `getAllWithAuthors()` и перебор результата циклом `for (const Book& b : ...)`.
