## Что такое HTTP (коротко)
Браузер подключается к серверу и отправляет текстовый **запрос**: `GET / HTTP/1.1` + заголовки. Сервер отвечает текстовым **ответом**:
```
HTTP/1.1 200 OK                            ← статус: 200 = всё хорошо
Content-Type: text/html; charset=utf-8     ← что в теле: HTML в кодировке UTF-8
Content-Length: 5161                       ← длина тела в байтах
Connection: close                          ← после ответа соединение закрывается
                                           ← пустая строка: дальше тело
<!DOCTYPE html> ...                        ← тело: сама страница
```
`charset=utf-8` обязателен, иначе русский текст в браузере превратится в кракозябры.

## Соответствие JS → C++
| http-hello-html.js | lab5_2 / lab5_3 (C++) |
|---|---|
| `require("http")` | `#include <winsock2.h>` + `#pragma comment(lib, "Ws2_32.lib")` (сокеты Windows) |
| (Node инициализирует сеть сам) | `WSAStartup` |
| `http.createServer(...).listen(3000)` | `socket` → `bind` (порт 3000) → `listen` |
| `function (request, response) {...}` — вызывается на каждый запрос | цикл `while (true) { accept(...) ... }` |
| `request` | `recv(client, ...)` (запрос читаем, но не разбираем) |
| `response.writeHead(200, {"Content-Type": ...})` | строка `"HTTP/1.1 200 OK\r\nContent-Type: ...\r\n"` |
| `response.write("<!DOCTYPE html>..." )` | строка `head` (начало страницы) |
| `response.write(a + " + " + b ...)` | `body += ...` (в 5.0.3 — строки таблицы `rows`) |
| `response.end("</body></html>")` | строка `tail` + `send(...)` + `closesocket(client)` |
| `console.log("Server running...")` | `std::cout << "Server running..."` |

Node сам считает `Content-Length` и сам переводит строки в байты. В C++ ответ собирается в одну строку `std::string` и отправляется `send`.

## Детали lab5_3
- `buildRows` читает `data/books.txt` и для каждой книги делает строку таблицы `<tr><td>...</td></tr>`. Это делается **один раз при запуске**, поэтому страница статическая.
- `escapeHtml` заменяет `& < > "` на `&amp; &lt; &gt; &quot;`, чтобы символ из данных не сломал разметку.
- Немного CSS в `<style>`: рамки, заливка заголовка, «зебра» строк, числа по правому краю.
- Сокет **IPv6 с отключённым `IPV6_V6ONLY`** принимает подключения и по IPv4 (`127.0.0.1`), и по IPv6 (`::1`). Браузер по адресу `localhost` может пойти любым путём, Node.js делает так же.
- `SO_EXCLUSIVEADDRUSE` не даёт двум серверам занять порт 3000 одновременно. Без него Windows позволяет node и нашему серверу сидеть на одном порту, и непонятно, кто ответит браузеру.
